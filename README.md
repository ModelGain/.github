# ModelGain GitHub organization profile

This public repository powers the [ModelGain organization overview](https://github.com/ModelGain).

GitHub renders [`profile/README.md`](profile/README.md) on the organization home page. The profile provides a concise, English-language entry point to the [official website](https://modelgain.com/), released software, services, and documentation.

## What belongs here

- A short, accurate introduction to ModelGain.
- Links to **published** products and their official distribution pages.
- Clear labels for work in development; no unsupported launch or open-source claims.
- Stable links to ModelGain's product catalog, WordPress services, blog, and contact page.

## What does not belong here

- Private repositories, internal architecture, unpublished credentials, or customer information.
- A duplicate marketing website, generated statistics, or live badges that depend on third parties.
- Release records for individual products: those belong to their product repositories or official distribution channels.

See [maintenance guidance](docs/MAINTENANCE.md) before changing public claims or links.
